# SchoolHub current application

Current application source copied from the local SchoolHub project on 4 October 2026.

Start with [CLAUDE_HANDOFF.md](CLAUDE_HANDOFF.md) for prerequisites, Windows setup, run commands, code locations, data handling, and deployment limitations. See [SOFTWARE_COMPLETE_HANDOFF.md](SOFTWARE_COMPLETE_HANDOFF.md) for the detailed module inventory.

The main frontend is `SchoolHub_School_Management_App_Complete.html`. The Node.js/PostgreSQL backend is in `schoolhub-server/`. Both shared module folders are required. GitHub alone does not run the complete app. Private configuration and school database records are not included.
